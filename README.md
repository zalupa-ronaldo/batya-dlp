# Батя качает

Простое приложение для Windows 10/11 x64: вставить ссылку, скачать видео, открыть в привычном проигрывателе. Интерфейс на русском, крупные кнопки, никакой установки Python. FastAPI работает только на этом компьютере; интерфейс открывается в браузере.

## Скачать и запустить

1. Откройте [последний выпуск](https://github.com/zalupa-ronaldo/batya-dlp/releases/latest) и скачайте **BatyaDLP-Windows-x64.zip**.
2. Правой кнопкой по архиву → **Извлечь всё**. Перенесите полученную папку на рабочий стол.
3. Дважды нажмите **Batya.exe** внутри папки. Автоматически откроется браузер.
4. Вставьте ссылку и нажмите **Скачать видео**. После загрузки нажмите **Смотреть**.

Распакуйте всю папку: рядом с EXE должны остаться `_internal`, `tools` и `licenses`. Для удобства можно сделать ярлык `Batya.exe` на рабочем столе. Установщик и права администратора не нужны. EXE не подписан платным сертификатом, поэтому Windows может показать предупреждение SmartScreen об неизвестном издателе; сверяйте источник и SHA-256 архива в выпуске.

## Что умеет

- Скачивание одного видео по ссылке через yt-dlp, очередь до 20 заданий.
- 1080p, 720p, максимальное качество или только звук в MP3. Приоритет H.264/AAC и MP4 для привычных Windows-проигрывателей; фактическое качество зависит от исходника.
- Прогресс, скорость, оставшееся время, отмена и повтор загрузки.
- Выбор папки обычным окном Windows или вводом пути.
- История последних 200 загрузок. **Смотреть** открывает файл в системном проигрывателе, **Папка** открывает Проводник.
- Кнопка обновления yt-dlp из официального стабильного выпуска с обязательной проверкой SHA-256 и запуска новой версии перед заменой. Обновление доступно, когда очередь пуста.
- yt-dlp, FFmpeg/ffprobe и Deno уже в ZIP; отдельная установка не требуется.

Закрытие вкладки не останавливает скачивание. Чтобы закрыть приложение, нажмите кнопку питания справа сверху. Повторный запуск EXE открывает существующее приложение. После аварийного завершения незаконченные задания можно повторить; `.part`-файлы позволяют yt-dlp продолжить поддерживаемые загрузки.

Настройки, история, журнал и обновляемая копия yt-dlp хранятся в `%LOCALAPPDATA%\BatyaDLP`. Видео по умолчанию — в `%USERPROFILE%\Downloads\Батя качает`. Смена папки действует на новые задания; ранее скачанные файлы не перемещаются.

Для скачивания и обновления нужен интернет. Ограничения сайтов, регионов и авторизации действуют и здесь. Вход в аккаунты, cookies, DRM и целые плейлисты не реализованы. Скачивайте материалы, на сохранение которых у вас есть разрешение. Если сайт изменился, сначала обновите yt-dlp. FFmpeg, Deno и сам интерфейс обновляются скачиванием нового ZIP.

## Разработка

Python 3.11+ (для Windows-релиза используется 3.12), FFmpeg в PATH. Для полного YouTube также установите [Deno](https://docs.deno.com/runtime/getting_started/installation/). Официальные Windows-бинарники положите в `tools/` либо используйте Python-версию yt-dlp в окружении разработки.

```sh
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
python -m pip install -e ".[dev,build]"
python -m batya
```

```sh
python -m pytest
ruff check .
python scripts/smoke.py
```

Smoke-тест поднимает локальный HTTP-сервер, создаёт короткий MP4 через настоящий FFmpeg и скачивает его настоящим yt-dlp через API. Он проверяет готовый файл, историю, повторный запуск и завершение. Не зависит от YouTube или внешних видео.

## Сборка Windows

```powershell
python -m pip install -e ".[dev,build]"
python scripts/build_windows.py
python scripts/smoke.py --exe dist/BatyaDLP/Batya.exe
```

Бинарные зависимости зафиксированы URL и SHA-256 в `scripts/tools.lock.json`; сборка отклоняет несовпадение. `python scripts/lock_tools.py` обновляет lock-файл через официальные GitHub Releases. Проверяйте изменения lock-файла перед коммитом.

GitHub Actions запускает проверки на Windows и Linux. Тег `v*` собирает ZIP, проверяет именно упакованный EXE и публикует GitHub Release с контрольной суммой. Сборка доступна и вручную через `workflow_dispatch`. Исходный код приложения — MIT. Сторонние программы остаются под своими лицензиями; см. [THIRD_PARTY.md](THIRD_PARTY.md), `licenses/` и manifest в ZIP.

## Устройство

Никаких Node.js, CDN, телеметрии или облачного бэкенда. Статические HTML/CSS/JS + FastAPI/uvicorn. yt-dlp запускается отдельным процессом без shell, его события JSON используются для прогресса и определения финального имени файла. Одна очередь ограничивает нагрузку на компьютер. Сервер слушает только `127.0.0.1` на свободном порту; случайный ключ запуска обменивается на HttpOnly/SameSite-cookie, проверяются Host и Origin. Пути для запуска файлов берутся из истории и проверяются по каталогу и расширению.
